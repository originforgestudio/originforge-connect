# Press kit

**OriginForge Connect** is a free, browser-based pixel-art multiplayer town for founders, builders and makers, made
in Manchester, UK, by OriginForge Studio. Players gather, craft, farm, duel, build homes and meet other people who
build things.

- Play: https://originforgeconnect.com/play/
- Website: https://originforgeconnect.com
- Studio: https://originforgestudio.co.uk
- Contact: contact@originforgestudio.co.uk

Screenshots are in the [screenshots](../screenshots) folder. Feel free to use them when writing about the game.
